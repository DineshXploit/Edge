# RIGHT TO FITNESS AI

A production-oriented Android application scaffold for an adaptive AI fitness coach built with Kotlin, Jetpack Compose, MVVM + Clean Architecture, Hilt, Room, DataStore-ready persistence, Retrofit/OkHttp-ready networking, Material 3, offline-first repositories, and security hardening.

## Current capabilities

- Dynamic fitness engine that calculates calories, macros, hydration, recovery, progressive overload, and personalized workout blocks from a user profile.
- Premium dark glassmorphism Compose UI with animated progress rings and interactive cards.
- Room-backed offline persistence for profiles, generated plans, and progress logs.
- Clean domain, data, DI, security, and UI layers designed for commercial expansion.
- Release build configuration with shrink/minify and strict cleartext-network blocking.

## Build

```bash
gradle :app:assembleDebug
```
